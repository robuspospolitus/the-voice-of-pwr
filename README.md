# GŁOS PWR

Aplikacja webowa stworzona w ramach Wakacyjnego Wyzwania KNSolvro, dająca studentom przestrzeń do wyrażania opinii i budowania społeczności akademickiej.

## O Projekcie
Głos PWr ma na celu ułatwienie studentom Politechniki Wrocławskiej dzielenia się opiniami oraz organizowania życia studenckiego w jednym miejscu.

## Funkcjonalności 
- opiniowanie prowadzących 
- opiniowanie programu studiów 
- szukanie osoby do akademika
